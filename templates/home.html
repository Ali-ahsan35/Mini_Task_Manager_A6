Professional Task Management System with REST API

REST API

Full-featured REST API for task management with proper HTTP methods and JSON responses

  • POST /api/tasks - Create task
  • GET /api/tasks - List tasks
  • GET /api/tasks/<id> - Get task
  • PUT /api/tasks/<id> - Update task
  • DELETE /api/tasks/<id> - Delete task

Advanced Filtering

Search, filter, and sort your tasks efficiently

  • ?status=todo - Filter by status
  • ?q=keyword - Search tasks
  • ?sort=due_date - Sort tasks

Beautiful, responsive UI to view and manage your tasks

Quick Start Guide

1

Create a Task (Postman/API)

POST http://localhost:5000/api/tasks
Content-Type: application/json

{
  "title": "Complete project",
  "description": "Finish the Flask assignment",
  "status": "todo",
  "due_date": "2026-02-10"
}
2

View Tasks

Navigate to /tasks to see all your tasks in the web interface

3

Manage Tasks

Use the API to update, filter, search, and delete tasks. The UI updates automatically!
